# DeepBlue Cards

A navy blue flashcard study website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` – page structure
- `style.css` – navy blue theme and layout
- `script.js` – flashcard demo (flip, shuffle, progress, saved best)

## Publish on GitHub Pages
1. Upload all files to the root of the repository.
2. Go to **Settings → Pages**.
3. Under **Source** choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save. Your site will appear at `https://muskanaslam6969.github.io/Muskan-Aslam/`.

## Add your own cards
Open `script.js` and edit the `DECKS` list at the top.
