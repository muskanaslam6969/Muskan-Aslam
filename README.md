# Muskan Aslam — Student Teacher Website

A responsive, beginner-friendly static website built with HTML, CSS and JavaScript.

## Files
- `index.html` — website content and sections
- `css/style.css` — layout, colors and responsive styling
- `js/script.js` — mobile navigation and current year
- `assets/favicon.svg` — browser tab icon

## Run locally
Open `index.html` in a browser. No installation or build command is required.

## Publish with GitHub Pages
1. Upload all files and folders to the root of your GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish and open the website URL shown on that page.

## Personalize before publishing
- In `index.html`, replace `hello@example.com` with the email address you want visitors to use.
- Edit the About Me paragraph, subjects and resources to match your real details.
- You can replace the initials `MA` with a photo later if you want.

This is a front-end website. It does not include a database, login system, or contact-form backend.
